# Titanic Survival - Exploratory Data Analysis (EDA)

## Project Description
This repository contains an *Exploratory Data Analysis* (EDA) project using the "Titanic - Machine Learning from Disaster" dataset. The main objective of this project is to perform data cleaning and analyze factors such as gender, ticket class, and age to observe their impact on the survival rate of Titanic passengers.

This project was created as a portfolio for the *Study Group* member application at the Artificial Intelligence Laboratory (AILab).

## Libraries Used
* **Pandas:** For data manipulation and cleaning.
* **Matplotlib & Seaborn:** For creating data visualizations.

## How to View the Project
Please open the `.ipynb` file in this repository to view the complete Python code along with the resulting data visualizations directly.
